# GGplot of trait pairs

GGplot of trait pairs

## Usage

``` r
ggplot_traitPairs(
  object,
  ...,
  drop_xlab = TRUE,
  legend_position = "bottom",
  legend_nrow = 1
)
```

## Arguments

- object, x:

  object of class \`traitPairs\`

- ...:

  additional parameters

- drop_xlab:

  drop xlab for all but last plot if \`TRUE\`

- legend_position:

  position of legend ("none" for none)

- legend_nrow:

  number of rows for legend

## Value

ggplot object
