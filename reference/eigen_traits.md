# Compare Eigen Traits with Original Traits

Compare Eigen Traits with Original Traits

## Usage

``` r
eigen_traits(
  object,
  sexname = sexnames,
  modulename,
  contr_object,
  eigen_object = eigen_contrast(object, contr_object)
)
```

## Arguments

- object:

  module list object

- sexname:

  name of sex combination

- modulename:

  name of module to examine

- contr_object:

  contrast object from \`conditionContrasts()\`

## Value

data frame
