# Module Band Object

Module Band Object

GGplot of module bands

## Usage

``` r
module_band(traitModule, response = responses[1], solo = FALSE)

ggplot_module_band(object, ...)

# S3 method for class 'module_band'
autoplot(object, ...)
```

## Arguments

- traitModule:

  object of class \`listof_wgcnaModules\`

- response:

  name of response for top row

- solo:

  do one response if \`TRUE\`

- object:

  object of class \`module_band\`

- ...:

  additional parameters

## Value

data frame of class \`module_band\`

ggplot object
