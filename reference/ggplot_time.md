# GGplot of object over time

GGplot of object over time

## Usage

``` r
ggplot_time(
  object,
  facet_strain = FALSE,
  xlab = "time",
  facet_time = NULL,
  ...
)
```

## Arguments

- object:

  of class \`strain_time\`

- facet_strain:

  facet by strain if \`TRUE\`

- xlab:

  label for X axis

- facet_time:

  name of column to facet on if not \`NULL\`

- ...:

  additional parameters

## Value

object of class ggplot2
