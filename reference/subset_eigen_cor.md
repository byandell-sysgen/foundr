# Subset of eigen_cor object

Subset of eigen_cor object

## Usage

``` r
subset_eigen_cor(
  x,
  facetname,
  colorname,
  facetmodules = flev,
  colormodules = clev,
  ...
)
```

## Arguments

- x:

  of class \`eigen_cor\`

- facetname:

  facet name

- colorname:

  color name

- facetmodules:

  names of color modules to keep

- colormodules:

  names of color modules to keep

## Value

data frame with colorname, facetname, correlation
