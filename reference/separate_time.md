# Separate Time Traits

Separate Time Traits

## Usage

``` r
separate_time(
  object,
  traitnames,
  timeunit = c("week", "minute", "minute_summary", "week_summary")
)
```

## Arguments

- object:

  data frame

- traitnames:

  character vector with \`dataset: trait\` names

- timeunit:

  name of time unit

## Value

data frame
